# my_torch Project

This project implements a mini neural-network framework and uses it to analyze chess positions.  
The goal is to recreate a lightweight version of a neural network module (tensor/autograd, layers, training, save/load) and then build a chess analyzer that can train or predict game states from FEN input.

Repository contents:
- `my_torch`: neural-network library
- `my_torch_analyzer`: chess training/prediction CLI
- `my_torch_generator`: network generator CLI
